# v1.3 final UI-only polish

Branch: `v1.3-decision-ui`. Base: `21e5fd2460360f627cbc045201c14420c0f6e150`.
No merge to `main`; the existing cloud diagnostic probe is preserved.

## Display changes

- Dashboard Persistence / switching now names the existing Region transition
  ratio, retaining transition count, comparable steps, Positioning count and gaps.
- Trajectory starts with one overview card: dominant recent Region / Positioning,
  Region and Positioning switching descriptions, current Region and the existing
  zero-boundary flag. Ties and unavailable observations retain existing semantics.
- Trajectory ribbon legends include only categories observed in its chronological
  valid recent window. Unknown categories have a neutral color. No palette changes.
- Green Relay publication freshness is separated from a gold latest-valid-state
  observation-time panel. Publication time, completed-through time and observation
  time are explicitly distinguished; the existing freshness formatter is reused.
- Advanced state-space and phase views remain collapsed by default.

Switching descriptions are presentation wording only: at most one third of
comparable steps changing is **Mostly stable**, at least two thirds is
**Frequent switching**, otherwise **Moderate switching**. Zero comparable steps
is **Unavailable**, never stable. These display bins are not model thresholds,
validation rules, signals or trading recommendations. Gap/segment exclusion is
the unchanged existing calculation. No new calculation fields enter derived data.
