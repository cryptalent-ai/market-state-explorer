## Installed execution chain

```text
Task Scheduler: MarketStateExplorerRelay (every 5 minutes)
  -> %SystemRoot%\System32\wscript.exe //B //Nologo "...\run_relay_hidden.vbs"
  -> sh.Run(quoted PowerShell -File command, 0, True)
  -> run_relay_hidden.ps1
  -> unchanged .venv\Scripts\python.exe scripts\publish_live_relay.py
  -> append publisher stdout AND stderr to relay.log
  -> Python exit code -> PowerShell exit -> WScript.Quit -> task result
```

All generated files live in `%LOCALAPPDATA%\MarketStateExplorerRelay`:
`run_relay_hidden.ps1`, `run_relay_hidden.vbs`, and `relay.log` (created on first
execution). No `cmd.exe /c` redirection chain is used.

The installer still downloads **current main**, verifies Python 3.12, creates
the venv, installs the package, retains the existing GitHub CLI authentication
flow, and performs one real live publish test. That test now goes through the
same hidden launchers and log as scheduled execution. Nonzero result aborts
before task registration/update. Venv/pip failures also abort explicitly.

Task registration uses structured executable/argument/working-directory fields
instead of a nested shell command. The five-minute repeat interval is indefinite;
overlapping scheduled instances are ignored. `-Force` updates the existing task.
Reinstallation updates source and overwrites launcher files without deleting the
install folder, log or venv, and does not purge `~/.market-state-explorer/cache`.
Only the specifically validated temporary extraction directory is cleaned.

PowerShell path literals escape apostrophes without expanding `$` or backticks.
VBS executable and script arguments are quoted separately. Generated PowerShell
has a UTF-8 BOM; VBS has a UTF-16LE BOM so Windows PowerShell 5.1 / WSH preserve
non-ASCII user paths. New logs use UTF-8; existing UTF-16LE manual-wrapper logs
retain their encoding on append. The launcher preserves the located GitHub CLI
path and configures Python stdout/stderr as UTF-8.

New tests cover:

- Real action-generation function: `wscript.exe`, quoted VBS argument, workdir.

- Main-download, auth, Python 3.12, five-minute task and no-cache-purge contracts.
- Real Windows PowerShell 5.1 and WScript executing a mock publisher via a real
  Python executable under a path with spaces: exit 0 / 7 / 23 are preserved.
- Unicode stdout/stderr and UTF-8 / UTF-16 repeated log append.
- Missing executable/publisher or unusable log path: never report success.
- Two uniquely named real Windows test tasks, registered twice and started with
  `Start-ScheduledTask`: task results **0 and 7** respectively, `PT5M` indefinite
  repetition, correct wscript action and both log streams. Test tasks are removed.
- Additional hashes freeze the v1.3.1 publisher, cache, live-data assembly and
  backward OI implementation; existing model/UI/freshness hash guards remain.

The restricted local sandbox cannot activate WSH COM reliably. Windows integration
was run outside that sandbox, using disposable fixture directories/tasks only.

miss completed runs because of time representation differences. The final
observer compares the scheduler's own before/after LastRunTime and checks task
state/result; this is test-harness logic, not publisher/model logic.

## Windows manual acceptance commands

Run only when ready to test this installer on the authorized Windows publisher
machine. This installs source from current main and performs a real comment write;
before merge that source is v1.3.1, while the launcher logic is from this branch.
After approval/merge, both source and package metadata are v1.3.2.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_windows_relay.ps1
$RelayRoot = Join-Path $env:LOCALAPPDATA 'MarketStateExplorerRelay'
Get-ScheduledTask -TaskName 'MarketStateExplorerRelay' |
    Select-Object -ExpandProperty Actions |
    Format-List Execute,Arguments,WorkingDirectory
Start-ScheduledTask -TaskName 'MarketStateExplorerRelay'
# Once State is no longer Running, inspect LastTaskResult:
Get-ScheduledTask -TaskName 'MarketStateExplorerRelay' | Select-Object TaskName,State
Get-ScheduledTaskInfo -TaskName 'MarketStateExplorerRelay' |
    Select-Object LastRunTime,LastTaskResult,NextRunTime
Test-Path -LiteralPath (Join-Path $RelayRoot 'relay.log')
Get-Content -LiteralPath (Join-Path $RelayRoot 'relay.log') -Tail 30 -Encoding UTF8
```

For an existing UTF-16 manual-wrapper log use `-Encoding Unicode` for inspection.
Observe the desktop during the manual start and next normal five-minute trigger:
no Python/PowerShell console may appear. Require `LastTaskResult = 0`, log exists,
real `Published relay` lines and audit JSON with future OI matches zero. Compare
completed-through across consecutive five-minute executions; it should progress
with completed bars while market age stays within the unchanged 15-minute guard.
Then rerun the installer and confirm the task still works and prior log entries
remain. No installer-added cache purge is permitted.
