## Default surfaces

Dashboard places full Region/Positioning, source freshness, existing boundary
status, recent dominance/transition counts, history frequency and validation
quality/N/scope above the matrix. Ribbon is oldest-left/latest-right. Five recent
states are newest-first. Validation shows Mean/Median ATR, difference vs baseline
ATR and its distinct 95% CI, Positive Rate, quality and Tail Warning. It uses the
bundled historical benchmark, never pretends Relay has forward validation.

State Map opens with current state, matrix, historical vs recent occupancy and
percentage-point differences, then finite-sample percentile/frequency descriptors.
Density + recent / Recent only / Full scatter are in a collapsed Advanced expander.

Trajectory opens with the chronological ribbon, descriptive summary, four shared
time-axis series with latest markers and Effort/Result zero lines, then a readable
Region transition table. 2D phase trajectory is only in collapsed Advanced.

Full primary labels wrap and HTML is escaped. Invalid optional numbers are NA,
not fabricated values. Summary transitions/deltas exclude missing-bar/segment
discontinuities. Percentiles and occupancy use only the selected visible valid
state history (Relay may publish fewer than the selected window). No thresholds
are used to invent stability or rarity classes.

## Outstanding acceptance / handoff

- A separate Streamlit Community Cloud preview has **not** been created. Follow
  `DEPLOYMENT.md` without touching production; local preview is verified.
- The timed **human** 3–5-second seven-question protocol remains for user
  acceptance. Automated rendering cannot certify human reading time.
- Optional 3×3 matrix and optional Positioning transition table were not added;
  these are explicitly optional in the spec, not missing required features.

All quantitative mathematics, rolling normalization, thresholds, boundary/event
definitions, Delta reconstruction, OI alignment, forward outcomes, validation
sampling/no-lookahead, Relay freshness and Archive fallback semantics are
**completely unchanged**. No new signals, optimization, ML or 3D.
